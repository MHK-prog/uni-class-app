# برنامهٔ کلاس‌ها

وب‌اپلیکیشن سبک و سازگار با موبایل برای دیدن کلاس‌های امروز یا فردا، وضعیت برگزاری و هفته‌های زوج و فرد.

## امکانات

- تشخیص خودکار روز و ساعت بر اساس منطقهٔ زمانی ایران (`Asia/Tehran`).
- جابه‌جایی میان برنامهٔ امروز و فردا.
- محاسبهٔ خودکار هفتهٔ زوج/فرد؛ مبنای پیش‌فرض، شنبهٔ ۳ اکتبر ۲۰۲۶ برابر با هفتهٔ زوج است. مبنا از داخل برنامه قابل تغییر است.
- وضعیت رنگی هر کلاس: در پیش، در حال برگزاری یا تمام‌شده.
- افزودن، ویرایش و حذف درس‌ها.
- ورود و خروج نسخهٔ پشتیبان JSON.
- نصب‌پذیر و قابل استفادهٔ آفلاین پس از نخستین بازدید در GitHub Pages.
- برنامهٔ شخصی فقط در حافظهٔ مرورگر همان دستگاه می‌ماند؛ سروری برای دریافت درس‌ها وجود ندارد.

## اجرای محلی

در همین پوشه اجرا کنید:

```powershell
python -m http.server 8000
```

سپس در مرورگر به `http://localhost:8000` بروید. برای نصب روی موبایل، پروژه را روی HTTPS منتشر کنید و از منوی مرورگر گزینهٔ افزودن به صفحهٔ اصلی را بزنید.

## انتشار عمومی با GitHub Pages

1. در GitHub یک مخزن جدید بسازید و فایل‌های همین پوشه را در ریشهٔ مخزن قرار دهید.
2. در مخزن وارد **Settings → Pages** شوید.
3. گزینهٔ انتشار از شاخه را انتخاب کنید؛ شاخهٔ `main` و پوشهٔ ریشه (`/`) را تعیین و ذخیره کنید.
4. نشانی نمایش‌داده‌شده در همان صفحه را باز کنید.

فایل درس‌های شخصی داخل پروژه نیست. هر بازدیدکننده باید برنامهٔ خودش را وارد یا بسازد. داده‌ها میان دستگاه‌ها همگام نمی‌شوند؛ برای انتقال دستی از خروجی/ورودی JSON استفاده کنید.

## وارد کردن برنامهٔ شخصی

فایل JSON را با دکمهٔ فلش رو به بالا انتخاب کنید. نمونهٔ ساختار:

```json
{
  "formatVersion": 1,
  "settings": { "anchorDate": "2026-10-03", "anchorParity": "even" },
  "courses": [
    { "title": "نام درس", "day": "دوشنبه", "start": "10:30", "end": "12:30", "week": "even", "room": "۲۱۲" }
  ]
}
```

برای هر هفته، مقدار `week` را `weekly` بگذارید؛ مقدارهای دیگر `even` و `odd` هستند. درس ناقص می‌تواند روز یا ساعت خالی داشته باشد.
